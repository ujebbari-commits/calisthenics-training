# Calisthenics Training Tracker

初心者から本格的にカリステニクスへ進むための、スマホ向け静的Webアプリです。

## 内容
- 週4回の固定メニュー（Pull / Push / Legs / Full Body + Skill）
- 任意の Mobility / Recovery メニュー
- 各種目のセット・回数・休憩タイマー
- 懸垂、ディップス、倒立、L-sitなどの基準値管理
- トレーニング履歴
- localStorageによる端末内保存
- JSONバックアップ
- PWA対応

## GitHub Pagesへの公開
1. このフォルダの中身をGitHubリポジトリのルートへアップロード
2. GitHubの `Settings > Pages`
3. `Build and deployment` で `Deploy from a branch`
4. Branchを `main`、Folderを `/(root)` に設定
5. Save

数分後、GitHub PagesのURLから利用できます。

## 方針
最初から毎セット限界まで行わず、基本は1〜2回余力を残します。スキル練習は疲労が少ない序盤に行います。
